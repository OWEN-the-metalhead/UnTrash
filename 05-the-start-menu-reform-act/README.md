## 🛠️ THE SETTINGS

*Written for Windows 11. Menu names can differ slightly between versions.*

### 1. Clean up the Start menu

1. Open **Settings → Personalization → Start**.
2. Turn off:
   - **Show recommendations for tips, shortcuts, new apps, and more**
   - **Show account-related notifications**
   - **Show recently added apps** *(optional)*
   - **Show recommended files in Start, recent files in File Explorer, and items in Jump Lists** *(optional)*

### 2. Unpin apps you don't want

1. Open **Start**.
2. Right-click a pinned app and choose **Unpin from Start**.

### 3. Clean up the taskbar

1. Open **Settings → Personalization → Taskbar**.
2. Under **Taskbar items**:
   - Set **Search** to **Hide** or **Search icon only**.
   - Turn off **Task view** if you don't use it.
   - Turn off **Widgets**.
3. To unpin a taskbar app, right-click it and choose **Unpin from taskbar**.

### 4. Turn off search highlights

1. Open **Settings → Privacy & security → Search permissions**.
2. Under **More settings**, turn off **Show search highlights**.

## ↩️ HOW TO UNDO

- Turn the same switches back on in the same places.
- To pin an app again, right-click it in **All apps** and choose **Pin to Start** or **Pin to taskbar**.
