## 🛠️ THE SETTINGS

*Written for Windows 11. Menu names can differ slightly between versions.*

### 1. Uninstall apps you don't use

1. Open **Settings → Apps → Installed apps**.
2. Find the app, click **⋯** next to it, and choose **Uninstall**.
3. Confirm when asked.

### 2. Remove optional features you don't use

1. Open **Settings → System → Optional features**.
2. Expand a feature you don't need and click **Remove**.

### 3. Clear out temporary files

1. Open **Settings → System → Storage → Temporary files**.
2. Tick the categories you want to clean. Leave **Downloads** unticked unless you've checked what's in it.
3. Click **Remove files**.

## ↩️ HOW TO UNDO

- **Apps:** reinstall them from the **Microsoft Store** or the developer's website.
- **Optional features:** go to **Settings → System → Optional features → View features**, find the feature, and add it back.
- **Temporary files:** these can't be restored. They aren't needed, so nothing needs undoing.
