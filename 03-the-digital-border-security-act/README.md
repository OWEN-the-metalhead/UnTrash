## 🛠️ THE SETTINGS

*Written for Windows 11. Menu names can differ slightly between versions.*

### 1. Stop apps from running in the background

This works for apps installed from the Microsoft Store.

1. Open **Settings → Apps → Installed apps**.
2. Click **⋯** next to the app and choose **Advanced options**.
3. Under **Background apps permissions**, set **Let this app run in background** to **Never**.

### 2. Find out what's using your memory

1. Press **Ctrl + Shift + Esc** to open **Task Manager**.
2. On the **Processes** page, click the **Memory** column to sort by usage.
3. To close something you don't need right now, select it and click **End task**. Don't end processes you don't recognize. Search for them first.

### 3. Turn off Edge background running

1. In Edge, open **Settings → System and performance**.
2. Turn off **Startup boost**.
3. Turn off **Continue running background extensions and apps when Microsoft Edge is closed**.

## ↩️ HOW TO UNDO

- **Background apps:** set the app's option back to **Power optimized** (the default) or **Always**.
- **Task Manager:** ending a task only lasts until the app is opened again or the PC restarts.
- **Edge:** turn both switches back on.
