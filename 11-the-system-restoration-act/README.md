## 🛠️ HOW TO RESTORE

*Written for Windows 11. Menu names can differ slightly between versions.*

### 1. Undo a single change

Each section of Untrash has its own **How to undo** section. Start there.

### 2. Go back to a restore point

1. Open **Start**, search for **Create a restore point**, and open it.
2. On the **System Protection** tab, click **System Restore**.
3. Pick the restore point you made before changing anything, then click **Next → Finish**.

> Restore points roll back settings, drivers, and installed programs. Your personal files are not affected.

### 3. Restore if Windows won't start

1. Hold **Shift** while clicking **Restart**, or let Windows fail to boot twice.
2. Go to **Troubleshoot → Advanced options → System Restore**.

### 4. Reinstall a removed app

1. Open the **Microsoft Store**.
2. Search for the app and click **Install**.
