## 🛡️ WHAT STAYS ON

These settings protect your PC. Check that they're on, and leave them on.

*Written for Windows 11. Menu names can differ slightly between versions.*

### 1. Antivirus

1. Open **Settings → Privacy & security → Windows Security → Virus & threat protection**.
2. Under **Virus & threat protection settings**, click **Manage settings**.
3. Make sure **Real-time protection** is **On**.

### 2. Firewall

1. Open **Windows Security → Firewall & network protection**.
2. Make sure the firewall is **On** for **Domain**, **Private**, and **Public** networks.

### 3. Core isolation

1. Open **Windows Security → Device security → Core isolation details**.
2. Turn on **Memory integrity** if your PC supports it.

### 4. Windows Update

1. Open **Settings → Windows Update**.
2. Click **Check for updates** and install what's available.
3. Restart when asked.

### 5. Account protection

1. Open **Settings → Accounts → Sign-in options**.
2. Set up a **PIN** or **Windows Hello** if you haven't already.
