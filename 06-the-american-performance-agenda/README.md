## 🛠️ THE SETTINGS

*Written for Windows 11. Menu names can differ slightly between versions.*

### 1. Set the power mode

1. Open **Settings → System → Power & battery**.
2. Set **Power mode** to **Best performance**.

> On a laptop this uses more battery. **Balanced** is a good middle ground.

### 2. Reduce visual effects

1. Open **Settings → Accessibility → Visual effects**.
2. Turn off **Transparency effects** and **Animation effects**.

For more control:

1. Press **Win + R**, type `sysdm.cpl`, and press **Enter**.
2. Go to **Advanced → Performance → Settings**.
3. Choose **Adjust for best performance**, or untick individual effects.
4. Tip: keep **Smooth edges of screen fonts** ticked, or text looks rough.

### 3. Turn on Game Mode

1. Open **Settings → Gaming → Game Mode**.
2. Turn **Game Mode** on.

### 4. Turn on Storage Sense

1. Open **Settings → System → Storage**.
2. Turn on **Storage Sense** to clear temporary files automatically.

## ↩️ HOW TO UNDO

- **Power mode:** set it back to **Balanced**.
- **Visual effects:** turn the switches back on, or choose **Let Windows choose what's best for my computer** in `sysdm.cpl`.
- **Game Mode / Storage Sense:** turn the switch off.
